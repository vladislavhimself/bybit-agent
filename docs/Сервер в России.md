# Российская машина как ретранслятор для режима Мосбиржи

## Как устроено

Бот целиком работает на нашем сервере в Германии: читает новости, анализирует их моделью, принимает
решения, пишет в Telegram. С Anthropic и Telegram он общается напрямую из Германии.

Российская машина ничего не решает и не торгует. На ней работают две вещи:

1. **WireGuard-туннель** до нашего сервера (UDP, порт 443). Российские провайдеры режут TCP до адресов
   зарубежных хостингов, а UDP-туннель проходит.
2. **Ретранслятор** `scripts/windows/relay.py` — маленький HTTP-прокси, слушает только внутри туннеля
   (10.8.0.2:8080). Через него голова из Германии ходит к T-Invest API, ISS Мосбиржи и российским
   новостным лентам, которые с зарубежных дата-центров недоступны. Ключей и токенов на российской машине нет.

## Что сделать владельцу машины (Windows)

1. Установить WireGuard для Windows: https://www.wireguard.com/install/ (обычная установка).
2. Открыть WireGuard → «Импорт туннелей из файла» → выбрать присланный `wg-bot.conf` → нажать «Подключить».
   Статус должен стать «Подключено», в строке «Последнее рукопожатие» появится время.
3. В PowerShell от администратора, в папке бота:

   ```powershell
   cd C:\src\bybit-agent\bybit-agent; git pull; powershell -ExecutionPolicy Bypass -File scripts\windows\install_relay.ps1
   ```

   Скрипт остановит и отключит локального бота (он больше не нужен), зарегистрирует задачу `BybitRelay`
   (запуск при старте системы) и откроет порт 8080 только для адресов туннеля.
4. Удалить файл `.env` из папки бота: ретранслятору ключи не нужны.
5. В WireGuard поставить галочку «Автозапуск при входе» для туннеля, либо (лучше) установить туннель как
   службу: в окне WireGuard правой кнопкой по туннелю нет такого пункта, поэтому через PowerShell от администратора:

   ```powershell
   & "C:\Program Files\WireGuard\wireguard.exe" /installtunnelservice "C:\путь\к\wg-bot.conf"
   ```

   Тогда туннель поднимается при загрузке Windows без входа пользователя.

## Проверка с нашей стороны

На немецком сервере: `wg show` показывает рукопожатие с 10.8.0.2, и
`curl -x http://10.8.0.2:8080 https://iss.moex.com/iss/index.json` отвечает. После этого в `.env` сервера
добавляется `RU_PROXY=http://10.8.0.2:8080`, включается рынок `moex`, и бот работает из Германии.

## Если туннель не поднимается

«Последнее рукопожатие» не появляется — значит провайдер режет и UDP. Тогда варианты: другой порт
(в `wg-bot.conf` поменять `Endpoint` на `177.3.217.105:51820`), либо другой канал связи — обсуждаем отдельно.
