# Сервер в России для режима Мосбиржи

Зачем: T-Invest API, ISS Мосбиржи и половина российских новостных лент отбрасывают запросы с серверов
за границей. Бот для Мосбиржи должен работать с российского адреса. Anthropic и Telegram из России
не работают — для них бот ходит через наш немецкий сервер как прокси (это настраивается на нашей стороне,
от владельца российской машины ничего не нужно).

## Что нужно от владельца машины

1. **Компьютер, который работает круглосуточно.** Подойдёт любой: старый ноутбук, мини-ПК, Raspberry Pi 4
   или арендованный VPS в России. Хватит 1 ядра, 1–2 ГБ памяти и 10 ГБ на диске. Интернет — обычный
   домашний, главное — российский провайдер.
2. **Linux.** Лучше всего Ubuntu Server 24.04 (бесплатно, образ: https://ubuntu.com/download/server).
   Debian тоже подходит. Windows не нужна: на ней бот запускать сложнее и ненадёжнее.
   Если это арендованный VPS — просто выбрать Ubuntu 24.04 при заказе.
3. **Доступ по SSH снаружи.** Два варианта, нужен один:
   - **А. Белый IP.** Если провайдер даёт публичный IP (это платная опция у большинства домашних
     провайдеров, 100–200 ₽/мес), на роутере пробросить порт 22 на этот компьютер и сообщить нам IP.
   - **Б. Без белого IP (обычная домашняя сеть).** Ничего на роутере не трогать: мы дадим одну команду,
     которая поднимет на машине постоянный обратный туннель до нашего немецкого сервера. Через него
     мы и будем заходить. Команду подготовим, когда машина будет готова.
4. **После установки Linux выполнить (один раз, под root или через sudo):**

   ```bash
   sudo apt update && sudo apt install -y openssh-server python3 python3-venv git curl chrony
   sudo systemctl enable --now ssh
   ```

   И добавить наш публичный SSH-ключ (пришлём отдельно) в файл `~/.ssh/authorized_keys` пользователя,
   под которым будем заходить (удобнее всего root или пользователь с sudo без пароля).
5. **Чтобы машина не засыпала и поднималась сама:**
   - в настройках питания отключить сон и гибернацию (на ноутбуке — закрытие крышки не должно усыплять);
   - в BIOS/UEFI включить «Power on after AC loss / Restore on AC power loss», чтобы после отключения
     света компьютер включился сам;
   - по возможности подключить через ИБП (UPS).
6. Сообщить нам: IP (вариант А) или просто «машина готова» (вариант Б), и имя пользователя.

## Что сделаем мы (ничего от владельца не требуется)

- Скопируем бота, поставим зависимости, настроим автозапуск через systemd и часы через chrony.
- Настроим файрвол: снаружи открыт только SSH.
- Направим запросы к Anthropic и Telegram через наш немецкий сервер, всё остальное — напрямую
  с российского адреса (T-Invest, ISS Мосбиржи, российские новости).
- Крипто-бот остаётся на немецком сервере, оба работают параллельно.

## Нагрузка и трафик

Процессор почти не нагружен, память 150–300 МБ, трафик — десятки мегабайт в час (новости и свечи).
На скорость домашнего интернета не повлияет.
