# Bybit Agent — автономный новостной + технический бот для USDT-перпетуалов

Статус: **v0.2, код завершён, на demo-счёте не проверен.** Запускать только в режиме `demo`
(виртуальный баланс Bybit, реальные цены), минимум месяц, прежде чем думать о реальных деньгах.

## Что делает

1. **Новости каждые 20 секунд** из 13 публичных Telegram-каналов (Watcher Guru, Cointelegraph, CoinDesk, Wu Blockchain,
   BWE, Unfolded, анонсы Binance и Bybit, зеркала твитов Маска, Truth Social Трампа и Белого дома), Truth Social
   напрямую через открытый API (посты Трампа с первоисточника каждые 30 с), плюс RSS изданий и API анонсов
   Binance/Bybit раз в минуту. Всё без ключей. Опционально CryptoPanic по ключу.
   **X (Twitter)**: при наличии `TWITTER_BEARER_TOKEN` бот подписывается через X Activity API на посты 12 аккаунтов
   (Маск, Трамп, Белый дом, ФРС, SEC, CZ, Сейлор, Walter Bloomberg, First Squawk, Unusual Whales, Watcher Guru,
   Cointelegraph) и получает их потоком в реальном времени. Оплата по факту, ~0.005$ за пост.
2. Дешёвая модель отсеивает мусор, основная (Claude) превращает новость в событие: тип, важность 0–10, направление,
   затронутые монеты, горизонт, «уже отыграно», «слух».
3. **Событие обрабатывается сразу**, не дожидаясь планового скана: открытые позиции против новости закрываются,
   затронутые монеты оцениваются заново и при сильном сигнале открывается сделка (в том числе в обратную сторону).
4. **Календарь будущих событий**: макро-релизы (CPI, NFP, PPI, ФРС) из ForexFactory, даты FOMC на 2026,
   опционально крипто-события CoinMarketCal. За 30 минут до и 15 после релиза новые входы запрещены,
   ближайшие события передаются модели как контекст.
5. **Историческая реакция** (`scripts/build_playbook.py`): 40 крупных событий 2020–2025, отклик BTC/ETH через
   1ч/4ч/24ч/72ч, статистика по типам событий. Используется как априорная оценка для модели и поправка к весу новости.
6. **Теханализ** раз в 5 минут по ~40 ликвидным парам: дневной режим (SMA50/200, RSI, пробой), тренд 1ч/4ч, ADX,
   пробой канала, объём, RSI и дивергенция, MACD, Bollinger (сжатие/выход), уровни поддержки/сопротивления по свингам,
   тайминг входа по 15м. Ставка финансирования и открытый интерес как сигнал позиционирования толпы.
6a. **Киты**: сообщения официального канала Whale Alert (переводы от 50 млн USD) разбираются без модели:
   на биржу = давление продаж, с биржи = накопление, минт стейблкоина = приток ликвидности. Идут в сигналы
   и в контекст модели как сводка потоков за 24 часа.
6b. **История 50 лет** (`research/`): S&P 500 с 1970, индекс доллара, VIX, BTC с 2011. Событийное исследование по
   50 крупным событиям рынка акций и 22 ранним событиям крипты, плюс проверка 15 правил ТА на дневных данных.
   Выводы вшиты в контекст модели и в дневной фильтр ТА (на дневках крипты работает импульс, а не покупка просадок).
7. **Сведение**: новость × вес + ТА × вес + позиционирование × вес. Четыре уровня размера. Conviction только при
   согласии всех сигналов и после того, как модель отдельно искала причины не входить.
8. **Риск**: риск на сделку 0.4–3% торгового капитала, стоп по ATR, плечо считается от стопа (потолок 15),
   лимиты убытка день/неделя, kill-switch по просадке 25%, запрет погони за движением >15% без новости.
9. **Выход**: два частичных тейка (40% на 1R, 35% на 2.5R), после первого стоп в безубыток, остаток трейлингом
   ступенями по R, тайм-стоп 48 часов.
10. **Защита прибыли**: каждый раз, когда торговый капитал вырос на 10% от базы, половина прироста уходит в резерв
    и больше никогда не участвует в торговле. Все лимиты и размеры считаются от торгового капитала без резерва.
11. **Telegram**: отчёт каждые 4 часа (баланс = торговый + резерв, просадка, позиции, расход на модель), каждая сделка,
    важные новости, команды.
12. **Самообучение**: после каждых 8 закрытых сделок модель разбирает журнал, пишет уроки и правит параметры в жёстких
    границах (`TUNABLE_BOUNDS` в `bot/config.py`). На demo применяется само, на live после `/approve`.
13. **Бюджет модели**: при превышении дневного лимита (по умолчанию 4$) до конца суток работает дешёвая модель.

## Установка

```bash
pip install -r requirements.txt
copy .env.example .env
```

Заполнить `.env`:

- `BYBIT_API_KEY` / `BYBIT_API_SECRET`. Для demo: bybit.com → Demo Trading → API. Права: только торговля.
- `ANTHROPIC_API_KEY` с console.anthropic.com.
- `TELEGRAM_BOT_TOKEN` от @BotFather, `TELEGRAM_CHAT_ID` от @userinfobot. Потом написать боту `/start`.

Проверка доступа (особенно с сервера в России):

```bash
python scripts/check_access.py
```

Если Anthropic или Bybit недоступны, задать `HTTPS_PROXY` в `.env`.

## Запуск

```bash
python -m bot.main --dry-run
```

Dry-run: всё работает, вместо сделок в Telegram приходят сигналы. Боевой demo-режим:

```bash
python -m bot.main
```

## Сервер: Docker, бот + n8n

```bash
docker compose up -d --build
docker compose logs -f bot
```

n8n будет на порту 5678. Данные бота в `./data`, логи в `./logs`.

## Команды в Telegram

| Команда | Действие |
|---|---|
| `/status` | баланс, резерв, просадка, позиции, статистика, расход на модель |
| `/why` | почему на последней проверке рынка не было входа: сколько пар отсеяно каким фильтром |
| `/shadow` | теневые сделки: чем закончились бы отклонённые сигналы, помогает ли каждый фильтр |
| `/stop` | запретить новые входы, позиции остаются под стопами |
| `/panic` | закрыть всё, отменить ордера и остановиться |
| `/resume` | возобновить после остановки или kill-switch |
| `/calendar` | ближайшие запланированные события |
| `/review` | принудительный разбор сделок моделью |
| `/approve` | применить предложенные правки параметров (live) |
| `/lessons` | список выученных правил |

## Бэктест и история

```bash
python scripts/fetch_history.py BTCUSDT ETHUSDT SOLUSDT --interval 60 --days 730
python backtest/backtest.py BTCUSDT ETHUSDT SOLUSDT --days 720 --split 0.6 --threshold 0.4
python scripts/build_playbook.py
```

Бэктест проверяет только техническую часть (исторических новостей с метками времени нет).
Результат на 2 годах BTC/ETH/SOL: чистый теханализ после комиссий около нуля или в минус.
Поэтому вес ТА в боте такой, что без новости или перекоса позиционирования входов почти не бывает.

## Теневые сделки

Каждый отклонённый сигнал, который прошёл бы без одного фильтра или почти дотянул до порога, записывается
как виртуальная сделка (одна на монету, сторону и причину за 12 часов). Через 3 часа и дальше каждые 3 часа
бот проверяет её на реальных 5-минутных свечах по тем же правилам выхода: стоп, тейки, безубыток, защита
прибыли, тайм-стоп. Считаются два варианта: вход сразу по рынку и вход на откате.

По каждой причине отказа копится статистика: если отклонённые фильтром сделки в среднем в минус, фильтр
помогает; если в плюс, мешает. Разбор (самообучение) запускается не только после 5 реальных сделок,
но и после 20 новых теневых. По теневым он может подстраивать порог входа, фильтр позднего входа
и глубину отката, в жёстких границах и не больше чем на 20% за раз.

## Структура

```
bot/config.py     настройки, границы самообучения
bot/exchange.py   Bybit V5 (pybit): данные, ордера, позиции
bot/news.py       сбор новостей: Telegram-каналы, RSS, анонсы бирж, CryptoPanic
bot/calendar.py   будущие события: ForexFactory, FOMC, CoinMarketCal
bot/analyst.py    Claude: классификация новостей, второе мнение, учёт расходов
bot/playbook.py   историческая реакция по типам событий
bot/ta.py         индикаторы и сводка по инструменту
bot/signals.py    сведение сигналов и уровни уверенности
bot/risk.py       резерв прибыли, лимиты, kill-switch, размер позиции
bot/executor.py   вход, частичные тейки, безубыток, трейлинг, выход по новости
bot/journal.py    SQLite: новости, события, сделки, уроки, equity
bot/review.py     самообучение (по реальным и теневым сделкам)
bot/shadow.py     теневые сделки: запись отклонённых сигналов и проверка на свечах
bot/notify.py     Telegram
bot/main.py       поток новостей + главный цикл
```

## Что ещё не сделано

- Нет проверки на demo-аккаунте: первый запуск может вскрыть ошибки в ордерах.
- Нет архива исторических новостей, новостная часть не бэктестирована. Список событий в playbook составлен
  по памяти модели, время части событий приблизительное.
- Поток X Activity API написан по документации, но не проверен с реальным токеном. Первое подключение покажет,
  хватает ли app-токена для событий post.create или нужна авторизация пользователя.
- Нет ончейн-данных (крупные переводы, разблокировки токенов без CoinMarketCal).
- Резерв прибыли программный: деньги остаются на торговом счёте, бот их просто не считает. Перевод в Funding-кошелёк
  можно добавить после проверки на demo.
